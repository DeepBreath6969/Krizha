# KRIZHA Visualizer Pro

A professional, single-file **Lyrics Visualizer** built entirely with **HTML, CSS, and JavaScript**.

KRIZHA Visualizer Pro transforms lyrics into an animated ASCII-style visual experience using the letters **K R I Z H A**, complete with dynamic themes, smooth transitions, particle effects, and real-time rendering—all without external libraries, frameworks, or build tools.

## Features

* Real-time lyric playback
* KRIZHA ASCII text renderer
* Multiple built-in themes

  * Rainbow
  * Matrix
  * Cyberpunk
  * Fire
  * Ice
  * Monochrome
* Animated transitions

  * Fade
  * Fade Out
  * Zoom
  * Wave
  * Glitch
* Adjustable glow intensity
* Zoom controls
* Customizable text size and grid size
* Adaptive performance mode
* Particle effects
* Vignette effect
* Chromatic aberration
* Fullscreen mode
* Screenshot export
* Import and export lyrics (.txt)
* Drag-and-drop lyric loading
* Automatic settings persistence using LocalStorage
* Responsive design for desktop and mobile
* Runs completely offline

## Lyric Format

Each lyric line follows the format:

```text
start|duration|transition|theme|text
```

Example:

```text
0|3000|fade|rainbow|Hello World
3000|3000|zoom|cyberpunk|Welcome to KRIZHA
6000|2500|wave|matrix|Enjoy the Visualizer
```

## Built With

* HTML5
* CSS3
* Vanilla JavaScript
* Canvas API

No frameworks.

No Node.js.

No external libraries.

Everything is contained in a single **index.html** file.

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Press **Play**.
4. Edit or import your own lyrics.
5. Enjoy the visualization.
